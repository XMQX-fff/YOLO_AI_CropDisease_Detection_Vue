# 智慧农业项目设计系统规范

## 设计理念
- **科技农业**: 结合现代科技与农业元素，体现智能化、数据化
- **生态友好**: 使用自然、环保的色彩体系
- **简洁实用**: 界面简洁明了，功能实用性强
- **数据可视化**: 强调数据展示和图表可视化

## 色彩体系

### 主色系（农业科技主题）
- **主色**: #2E7D32 (深绿色 - 代表农业、生态)
- **辅助色**: #4CAF50 (鲜绿色 - 代表生长、健康)
- **科技蓝**: #2196F3 (科技蓝 - 代表智能化)
- **温暖黄**: #FF9800 (橙色黄 - 代表阳光、丰收)
- **警告色**: #F44336 (红色 - 代表警告、危险)

### 中性色系
- **标题文字**: #263238 (深灰蓝 - 专业稳重)
- **正文文字**: #546E7A (中灰蓝 - 舒适阅读)
- **辅助文字**: #90A4AE (浅灰蓝 - 次要信息)
- **边框**: #CFD8DC (浅灰 - 分割线)
- **基础背景**: #F5F7FA (浅灰白 - 页面背景)
- **卡片背景**: #FFFFFF (纯白 - 内容卡片)

### 农业特色色彩
- **土壤色**: #795548 (棕色 - 代表土地)
- **植物绿**: #388E3C (植物绿 - 代表作物)
- **水蓝色**: #03A9F4 (水蓝 - 代表灌溉)
- **阳光黄**: #FFC107 (金黄 - 代表阳光)

## 字体规范
- **主字体**: "Helvetica Neue", Helvetica, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", Arial, sans-serif
- **数据字体**: "Roboto", "Segoe UI", "Helvetica Neue", sans-serif (用于数据展示)
- **代码字体**: Consolas, Monaco, "Andale Mono", "Ubuntu Mono", monospace

### 字号层级
- **超大标题**: 28px (页面标题)
- **大标题**: 22px (模块标题)
- **标题**: 18px (卡片标题)
- **副标题**: 16px (次级标题)
- **正文**: 14px (主要内容)
- **辅助文字**: 12px (说明文字)
- **微小文字**: 10px (标签、备注)

## 间距系统 (基于8px网格)
- **微小间距**: 4px
- **基础间距**: 8px
- **中等间距**: 16px
- **大间距**: 24px
- **超大间距**: 32px
- **特大间距**: 48px

## 圆角规范
- **微小圆角**: 2px (输入框、按钮)
- **基础圆角**: 6px (卡片、模块)
- **大圆角**: 12px (特殊卡片、头像)
- **全圆角**: 50% (圆形元素)

## 阴影规范
- **弱阴影**: 0 1px 3px rgba(0, 0, 0, 0.12) (轻量级元素)
- **基础阴影**: 0 3px 6px rgba(0, 0, 0, 0.16) (卡片、浮层)
- **强阴影**: 0 6px 12px rgba(0, 0, 0, 0.2) (模态框、重要卡片)
- **悬浮阴影**: 0 8px 16px rgba(46, 125, 50, 0.15) (交互元素悬停)

## 动效规范
- **基础过渡**: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)
- **快速过渡**: all 0.2s cubic-bezier(0.4, 0, 0.2, 1) (按钮、交互)
- **慢速过渡**: all 0.5s cubic-bezier(0.4, 0, 0.2, 1) (页面切换)
- **弹性动效**: all 0.6s cubic-bezier(0.68, -0.55, 0.265, 1.55) (特殊效果)

## 图标系统
- **基础图标**: Element Plus图标库
- **农业图标**: 自定义农业相关SVG图标 (植物、天气、传感器等)
- **数据图标**: 图表、统计相关图标
- **操作图标**: 交互操作图标
- **尺寸规范**: 
  - 小图标: 16px
  - 中图标: 24px (默认)
  - 大图标: 32px
  - 特大图标: 48px

## 农业主题元素
- **自然渐变**: 使用绿色到蓝色的渐变代表生态到科技
- **植物纹理**: 在背景中使用微妙的植物纹理
- **数据卡片**: 卡片设计融入数据可视化元素
- **状态指示**: 使用农业相关的状态指示器 (健康、警告、危险)

## 响应式断点
- **移动端**: < 768px
- **平板端**: 768px - 1024px
- **桌面端**: > 1024px
- **大桌面端**: > 1440px
